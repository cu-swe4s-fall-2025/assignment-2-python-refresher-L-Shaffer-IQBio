# python-refresher

### Installation

Download data set

```bash
curl -L "https://docs.google.com/uc?export=download&id=1Wytf3ryf9EtOwaloms8HEzLG0yjtRqxr" -o Agrofood_co2_emission.csv
```

### Dependencies

- python3

### Useage

Run print_fires.py script to process csv

```bash
python3 print_fires.py
```
